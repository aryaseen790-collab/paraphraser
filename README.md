# Paraphraser

A free paraphrasing website powered by Claude Haiku (`claude-haiku-5-5`), built with Next.js, Tailwind CSS, Upstash Redis and Cloudflare Turnstile.

## Quick start

```bash
npm install
cp .env.example .env.local   # then fill in the values
npm run dev                  # http://localhost:3000
```
